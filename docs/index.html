Cómo se arma cada acuerdo

Se reúnen los archivos oficiales de la ALADI (el depositario de los acuerdos), se quitan las copias repetidas y se pasan a texto: con pdftotext los que tienen texto y con OCR (tesseract) los escaneados. Las listas de productos se leen como tablas cuando hace falta para Paraguay. Los PDF originales no se publican aquí; cada página indica la fuente.

Código en GitHub. Datos de comercio y uso de los acuerdos: Comercio exterior de Paraguay y acuerdos comerciales.
